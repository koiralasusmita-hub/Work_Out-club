 Workout Club: Milestone 1
 Keep workout.py and Workout_log.csv in the same folder. Requires matplotlib: pip install matplotlib
Run: python3 workout.py
It reads the log into a dictionary: exercise -> weights by week.
Question 1: prints whether each exercise made progress, stayed the same, or dropped from week 1 to week 3.
Question 2: prints the average weight for each exercise over 3 weeks.
Question 3: prints the total weight lifted per exercise, then shows a bar chart (close it to finish).
SELF-CHECK asserts run before the chart and print "All checks passed".
